Attempts to nerf armour and especially the protection enchantments

Also allows for the infininte scaling of armour and protection enchantments with the calculation never providing 100% resistance or providing negative resistance
For infinite scaling to work you will need Attribute Fix to make armour able to go above 30: https://www.curseforge.com/minecraft/mc-mods/attributefix/files/7115922

Please note this project is mainly intended for internal use on some larger gamemode projects, that being said there is an extensive config if you want to use/customise it
