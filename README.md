Attempts to slightly nerf armour and really nerf the protection enchantments while allowing for both to scale infinitly 

Fully configurable with an online graph for testing configs: https://www.desmos.com/calculator/98516vuxmp

I highly recommend you include methods of health scaling alongside this as it helps make the armour curve feel even smoother


For infinite scaling to work you will need Attribute Fix to make armour able to go above 30: https://www.curseforge.com/minecraft/mc-mods/attributefix/files/7115922



Please note this project is mainly intended for internal use on some larger gamemode projects, that being said there is an extensive config if you want to use/customise it and you can raise an issue here if you have any questions/problems
